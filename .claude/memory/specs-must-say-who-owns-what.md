ผู้ใช้ขอชัดเจนว่าเวลาเขียนสเปก field สำคัญ ต้องตอบให้ครบ 4 ข้อ: **ใครเป็น source · เปลี่ยนเมื่อไร · เคลียร์/เริ่มใหม่เมื่อไร · ใครต้อง handle logic บ้างและที่ไหน** (พร้อมคอลัมน์ "ถ้าไม่ทำจะเกิดอะไร")

**Why**: ตอนเขียนหัวข้อ `version` แบบนี้ **ขุดเจอบั๊ก 3 ตัวทันที** ที่ไม่มีใครเห็นมาก่อน — WMS ขยับ version ตอนที่ไม่มีข้อความออกไป (เลข 3 ฝั่งไม่ตรงกันตลอดกาล) · vendor ไม่อัปเดต version จาก `cartons_issued` · และข้อที่สเปกสั่งไว้ว่า "เราต้องเทียบค่าที่ vendor echo กลับมา" ไม่เคยมีใคร implement เลย

**How to apply**:
- เขียนเป็นหัวข้อของตัวเอง (เช่น สเปก vendor §2.2 `version`) ไม่ใช่ซ่อนเป็นแถวในตาราง field
- ใส่ตาราง "ใครต้องทำอะไร" แยกตามฝั่ง (WMS / Proxy ของเรา / vendor) — ระบุด้วยว่าฝั่งไหน **ห้ามตีความ** ค่านั้น
- พอเขียนเสร็จให้ **ไล่เช็คว่าโค้ดทำตามที่เขียนจริงไหม** ทุกข้อ ถ้ายังไม่มีใครทำก็ทำให้ครบ ไม่ใช่ปล่อยให้สเปกพูดถึงสิ่งที่ไม่มีอยู่
- ของที่ "ไม่มีข้อความออกไปหาปลายทาง" ห้ามขยับตัวเลขที่ปลายทางต้อง echo กลับ — ไม่งั้นสัญญาณเทียบค่าใช้ไม่ได้ทั้งระบบ
