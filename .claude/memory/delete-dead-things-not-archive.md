**"ผมอยากให้เหลือแค่ตัวที่ใช้"** — ของที่เลิกใช้แล้วให้**ลบทิ้ง** ไม่ใช่ย้ายเข้า `_archive/` (เคยทำแบบนั้นแล้วสุดท้ายผู้ใช้สั่งลบทั้งโฟลเดอร์ 37 MB)

**Why**: ซากที่ค้างอยู่หลอกคนอ่านให้เข้าใจผิดว่ายังต้องทำ เช่น comment ที่ยังบอกว่าใช้ `x-consistent-hash` ทั้งที่เลิกไปแล้ว · จอ outbox ที่ยังเขียนว่า "worker เป็นคนอ่านแถวนี้" ทั้งที่กลับทิศไปแล้ว · schema 20 ตารางของสายงานอื่นที่ทำให้คิดว่าต้องสร้างครบถึงจะรันได้

**How to apply**:
- ก่อนลบโฟลเดอร์/ไฟล์ **ตามเก็บทุก reference ที่ชี้ไปหามันก่อน** (`grep -rn`) ไม่ให้เหลือ path ตาย · ตัวชี้แบบ "ฉบับก่อนหน้า: ..." ให้ลบทั้งบรรทัด ส่วนที่อยู่กลางประโยคให้แทนด้วยคำอธิบายกลาง ๆ
- **บันทึกการตัดสินไว้ใน gap log** — ประวัติศาสตร์เก็บไว้ที่นั่นที่เดียว ไม่ต้องเก็บไฟล์เก่าไว้ทั้งไฟล์
- โฟลเดอร์นี้ **ยังไม่ commit** (untracked) ⇒ ลบแล้วกู้จาก git ไม่ได้ · ถ้าจะลบของใหญ่ให้ถามยืนยันก่อน แล้วรายงานว่าอะไรหายไปบ้าง
- ของที่ต้องเก็บไว้เสมอ: master data (`dispatch_station` ฝั่ง WMS · config จำนวนช่องฝั่ง vendor) และตารางของสายงานอื่นที่ปนอยู่ใน schema เดียวกัน
